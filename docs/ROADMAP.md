# Roadmap

0. Foundation: monorepo, CI, schema, private storage, contracts, static workspace shell.
1. Identity and projects: verified Neon Auth sessions, trusted origins, workspace authorization, project CRUD, integration tests.
2. Editorial workflow: sources, script editor, versions, approvals, exports.
3. Media basics: private uploads, signed URLs, FFmpeg metadata/transcode, SRT/VTT editor.
4. AI assistants: provider registry, capability metadata, quota/cost gates, script and SEO assistants, optional TTS.
5. Video workflow: clip candidates, vertical assembly, subtitles, optional video providers, retries/cancellation.
6. Distribution: official social APIs, scheduling, usage dashboard, audit, monitoring, backup drills.

Each phase requires feature-level acceptance tests, not build-only verification.
